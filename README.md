
#INSTALATION
* Clone repositori

* CMAKE
	** Download and install last version [website](https://cmake.org/downloads)

* Visual Studio Code
	** Download and install [website](https://code.visualstudio.com/download)

* ext: dos-dev [website](https://markeplace.visualstudio.com/items?itemName=badlogicgames.dos-dev)
	** On VSC look for "dos-dev" extension and install it
	** Ctrl+Shift+P
	** DOS: Install Tools
	** Select "djgpp" as dev kit

* Allegro
	** Download cross-compilation DJGPP/Allegro,   [website](https://www.mrdictionary.net/allegro/#cross)
	** Extract "djgpp/allegro/include" folder on "/[HOME]/.dos/djgpp/" as "allegro"
	** Extract "djgpp/allegro/lib/djgpp/*.a" on "/[HOME]/.dos/djgpp/lib/"

* Open project folder with VSC

* Test with F5
